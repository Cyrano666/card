# 微信小程序适配说明

小程序代码位于 `miniprogram/`，与网页端共用 CloudBase PostgreSQL 数据库和现有表结构。小程序使用微信原生身份自动登录，不再显示网页端的手机号登录表单；同一个微信身份可以创建空间，也可以用邀请码加入空间。

## 建议填写的小程序资料

名称建议先使用：`一起打卡双人小屋2026`。如果控制台提示重名，可依次尝试 `一起打卡小屋2026`、`我们的打卡空间2026`、`双人打卡小屋2026`。名称需以微信公众平台实际校验结果为准。

简称建议：`打卡小屋2026`。

简介建议：`两个人一起创建任务、每日打卡、查看记录，照片和备注可选；微信身份自动登录。`

头像可直接使用项目内的 [`miniprogram/assets/avatar-144.png`](../miniprogram/assets/avatar-144.png)，尺寸 144×144、PNG 格式且远小于 2 MB；不含政治、色情或误导性内容。

## 导入微信开发者工具

1. `miniprogram/project.config.json` 已配置小程序 AppID；如在其他电脑导入，请确认它仍为你的真实 AppID。
2. 在微信开发者工具中导入目录 `miniprogram/`，开发模式选择“小程序”。
3. 开发者工具中执行“工具 → 构建 npm”，生成 `miniprogram_npm/`，该目录已在 `.gitignore` 中忽略。
4. 在“云开发”中确认环境 ID 为 `fx-d8gsy0r867fcba5ca`（地域：上海），并检查 PostgreSQL 表、RLS 权限和云存储权限。
5. 勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”仅用于本地开发；提交审核前应按微信要求配置合法域名。

## 功能对应关系

- “今天”：创建/加入空间、创建和编辑任务、完成打卡、备注和可选照片、完成鼓励动画。
- “记录”：查看最近 30 天打卡记录和照片。
- “我们”：查看和复制邀请码、查看当前微信身份、切换空间或退出微信身份。

照片上传使用 `wx.cloud.uploadFile`，路径为 `checkin-photos/<householdId>/...`，并将 fileID 写入 `checkins.photo_url`。如果控制台尚未开通 CloudBase 云存储，请先创建存储桶并设置小程序读写权限；不选择照片时打卡不受影响。

## 提交前检查

- 已替换真实 AppID，开发者工具不再显示 `touristappid`。
- 开发者工具预览真机时，创建空间、复制邀请码、另一微信加入、创建任务、打卡、记录页和退出登录均可操作。
- CloudBase PostgreSQL 已执行 [`../supabase/cloudbase-pg-schema.sql`](../supabase/cloudbase-pg-schema.sql)。
- 小程序上传密钥和 IP 白名单已在公众平台配置；代码上传前不要把密钥提交到仓库。
- 先上传体验版测试，再提交审核和发布。当前仓库只提供适配代码，不会替你绕过 AppID、资质或审核流程。
